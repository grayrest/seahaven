# Fork call sites that still reach the host.
#
# `cargo xtask check lint` lints every fork for `clippy::disallowed_methods`
# after the workspace, and compares what it finds against this file. A site that
# is not listed fails the gate; a listed site that no longer fires fails it too,
# per D13's mirror rule -- otherwise the list accumulates entries that describe
# nothing and stops measuring.
#
# One line per (file, banned method) with a count. Line and column are
# deliberately absent: they move for reasons that have nothing to do with
# confinement, and a key that churns is a key nobody maintains.
#
# This is a **backlog with a ratchet**, not an acceptance. Every line below the
# first section is a call that asks the host what it should be asking the
# namespace, in the same way `uu_ln`'s `symlink` did before anyone noticed it
# writing outside the mount. Routing one means deleting or decrementing its
# line here.
#
# To regenerate after routing something, run the fork lint and read the error:
# it names the exact line to change.

# ---------------------------------------------------------------------------
# Deliberate, and not to be "fixed".
#
# Build scripts run at build time on the host, before any namespace exists;
# they are not sandboxed code.
#
# `uu_df` reads the *host mount table* -- `filesystem.rs` canonicalizes mount
# device names and `df.rs` resolves those same names -- which is host
# introspection, not namespace access. `uucore`'s `fsext` is the same class.
# `df` is not confined, by decision; see RESIDUAL-PATCHES.md.
#
# `uucore::perms` is deliberately left on `walkdir`: unreachable from anything
# bundled, and porting it needs a routed `chown` that does not exist.
#
# The `rustix` `*at` calls in `uu_mv` and `uucore::safe_traversal` sit below a
# descriptor that was already rooted through the namespace and inherit its
# confinement. Rooting is the patch; the `*at` calls under it are meant to be
# unchanged.
#
# `mkfifo`, `mknod`, `utimensat`, `UnixListener::bind` and a child's
# `Command::current_dir` have no facade equivalent. The ban list says "not
# expressible in the namespace yet" for each, and means it.
#
# `tempfile` and `env::temp_dir` are scratch space, which D38 places outside
# the namespace on purpose.
# ---------------------------------------------------------------------------
