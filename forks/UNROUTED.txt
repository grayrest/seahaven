# Fork call sites that still reach the host.
#
# `cargo xtask check lint` lints every fork for `clippy::disallowed_methods`
# after the workspace, and compares what it finds against this file. A site that
# is not listed fails the gate; a listed site that no longer fires fails it too,
# per D13's mirror rule -- otherwise the list accumulates entries that describe
# nothing and stops measuring.
#
# One line per (file, banned method) with a count. Line and column are
# deliberately absent: they move for reasons that have nothing to do with
# confinement, and a key that churns is a key nobody maintains.
#
# ---------------------------------------------------------------------------
# Deliberate, and not to be "fixed".
#
# `uu_df` reads the *host mount table*: `filesystem.rs` canonicalizes mount
# device names and `df.rs` resolves those same names. That is host
# introspection, not namespace access, and routing it would make the symlink
# resolution never fire. `df` is not confined, by decision; `uucore`'s `fsext`
# is the same class. See RESIDUAL-PATCHES.md.
#
# `uucore::perms` is deliberately left on `walkdir`: unreachable from anything
# bundled, and porting it needs a routed `chown` that does not exist.
#
# The `*at` calls in `uu_mv` and `uucore::safe_traversal` sit below a descriptor
# that was already rooted through the namespace and inherit its confinement.
# Rooting is the patch; the `*at` calls under it are meant to be unchanged.
#
# `uucore::fsxattr`'s two `list_deref` calls are `has_acl` and its sibling,
# which `ls -l` calls once per entry. The rest of that module now works on
# descriptors the vfs opened; these stay on the path deliberately, because
# routing them means an open per file listed where the path form is a single
# `getxattr`. What leaks is whether a file has attributes, not their contents.
#
# `mkfifo`, `mknod`, `utimensat`, `UnixListener::bind` and a child's
# `Command::current_dir` have no facade equivalent. The ban list says "not
# expressible in the namespace yet" for each, and means it.
#
# `tempfile` and `env::temp_dir` in `uu_sort` and `uu_tac` are scratch space,
# which D38 places outside the namespace on purpose. `sed`'s temp file is *not*
# in this class -- see the backlog.
#
# Build scripts are exempted at the source instead of here, with a
# `#![allow(clippy::disallowed_methods)]` and the reason: a denied lint is an
# error, and an error in a build script aborts the crate before its library is
# analysed. That is not hypothetical -- it hid `uucore`'s and `sed`'s entire
# libraries from this gate until 2026-08-21.
# ---------------------------------------------------------------------------
