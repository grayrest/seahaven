# The uucore features `coreutils.all` resolves to, frozen (D4).
#
# Not a style check. The route/leave triage in
# plans/2026-08-18-uucore-fork.md rests on which uucore modules actually
# compile, and six modules with filesystem access are excluded from the codemod
# *because they are not built*: benchmark, proc_info, selinux, smack,
# systemd_logind, uptime. Enabling any of those features -- directly, or
# transitively by adding a utility -- silently ships 29 unrouted sites that
# read /proc, /sys and /etc/mtab.
#
# So a change here is a decision, not a diff to wave through. If a feature
# appears, decide whether its module routes, leaves, or needs hand-routing,
# record it in the plan's table, then run `cargo xtask gen uucore-features`.
#
