# seahaven: the platform

D10, D17–D19, D25, D43 and D45, and the thing this repository has been building
toward without yet naming as a milestone. Everything so far confines a *shell*.
Nothing yet lets Roc code run inside that confinement, which is the point of the
project: seahaven is meant to replace `basic-cli` as `~/dev/roc/rocjust`'s
platform, and the shell surface is the means.

> **Rewritten after adversarial review.** The first draft was read by four
> independent reviewers and did not survive. It miscounted the surface — it
> missed `Random` and `Utc` entirely, which are two of the six members of D15's
> session tuple; it cited D9, D15, D30 and D36 by their headlines while each
> carries a `Corrected:` amendment that changes the meaning; it claimed
> `check ban` would guard the new crate, when `check_ban` lints one fixture and
> never touches workspace code; and all eight of its gates were vacuous, weak,
> or described a comparison the differential harness cannot perform. What
> survived is the three decisions the owner made — native tier first,
> handle-shaped `Cmd`, synthesized signal queue — and none of the reasoning
> underneath them. This is the replacement, not a patch. The original is
> `da6e5878`.

## What is actually this repository's

rocjust is two halves and only one is a client of this work. `just/` is a Roc
**package** — lexer, parser, analyzer, evaluator, all pure — and contains zero
platform calls, checked rather than assumed. `app/` is the CLI and holds every
effect the port performs. That is the surface.

Stated up front so the milestone is not read as delivering more: **the wasm tier
is not in it, and neither is the parallel scheduler.** D17 makes wasm the
default tier and native the trusted opt-in; this builds native first, and "The
tiers disagree about who owns `main`" below says what that costs. D25's
`spawn`/`wait_any` is in the ABI and its scheduler is not.

**Fourteen of the 57 are pure and reach no host at all** — `Path.utf8`,
`display`, `join`, `to_os_str`; all four `Cmd` builder calls; every `OsStr`
call; `Signal.name`; `IOErr.to_str`. That is 125 of the 299 sites, and the
distinction matters twice: they need no routing, and a table that does not
separate them overstates the effect surface by a quarter. **43 calls are
effectful**, and that is the number the gates count against.

**`Random` and `Utc` are not incidental.** D15's session is
`(mounts, cwd, env, stdio, clock/RNG, locale)` and D14's hermetic mode turns on
exactly the clock and the RNG. `app/main.roc:9007` names a temp directory from
`Random.seed_u64!()`, so a predictable seed there is a collision and a
predictable-path problem rather than a cosmetic one. These are the two effects
in the surface carrying the most policy, and the first draft asserted they did
not exist.

**What is genuinely out.** `http_*` and `tcp_*` — though D9's own `Corrected:`
reads *"Nothing enforces the network-free property — tokio is already built with
the `net` feature"*, so their absence is a choice this milestone makes rather
than a property it inherits. `sqlite_*`, `sleep_*` and `locale_*` are uncalled.
That accounts for 15 of the 33 unimplemented effects. The other 18 —
`dir_create!`, `file_write_bytes!`, `file_open_reader!`, `file_read_line!`,
`file_size_in_bytes!`, `file_is_readable!`, `file_is_writable!`,
`file_time_{accessed,modified,created}!`, `file_hard_link!`, `file_rename!`,
`stdout_write_bytes!`, `stderr_write_bytes!`, `stdin_bytes!`,
`tty_{enable,disable}_raw_mode!` and `env_tz_offset!` — are simply not called by
this consumer. They are deferred work, named so the deferral is visible.

**D45's collapse is a real concession, and it is wider than UTF-8.**
basic-cli's `NativePath` is the three-way union D45 rejected, and 44 of the 124
`Path` sites are `Path.utf8`, so the app already builds paths from strings. But
`VirtualPath` narrows *further*: per D12 it rejects colons, Windows reserved
device names, and trailing dots or spaces, **on every platform**. A justfile
naming `notes:draft` or `con.txt` builds under basic-cli and is unnameable here.
That is the concession, it is unmeasured, and measuring it against the corpus is
step 2's first task.

## What is already true — and what is not

**True.** The filesystem effects map onto `brush-vfs` closely, though not one
for one: `Vfs::open` returns a `File`, so `file_read_utf8!` is open + read +
validate, and `Vfs::read_dir_names` returns bare names where `dir_list!` returns
paths. `path_type! → symlink_metadata` and `path_canonicalize! → canonicalize`
do map directly, and `canonicalize` is verified to return a virtual path and
never a host one. D2's execution predicate and D24's broker exist and are
tested.

**Not true, and the first draft said otherwise.**

- **D30's trampoline does not exist.** One comment in the tree, no code. D2 and
  D24 exist; the third leg does not. D30 also carries a correction — the
  trampoline is unbounded and needs a depth cap of 256 — with no implementation
  to cap.
- **D22's `/bin` does not exist**, so D30's `exe_path! → /bin/just` names a path
  in a directory nothing synthesizes. `wellknownvars.rs` refers to D22 in the
  future tense.
- ~~**D28's per-job output buffering does not exist.**~~ **Built since** as
  `brush_platform::stdio` — an ordered segment log, separate on the wire and
  merged only at render. It lives in `brush-platform`, not `brush-core`: it
  buffers the *guest's* output, which is where the stdio effects are.
- **D43's handle tables do not exist** — no generational indices, no frame
  stack, no reaping.
- **`check ban` does not lint crates.** It lints
  `xtask/fixtures/banned-fs-access` and proves the *config* is complete and
  switched on. Reach over real code is `check lint`'s `clippy --workspace`, and
  workspace membership is an explicit 12-entry list with no globs. A `staticlib`
  linked by `roc` rather than by cargo is exactly the shape that put `forks/`
  outside the workspace.
- **The ban covers filesystem and cwd only** — all 199 entries. Nothing bans
  `std::io::stdout`, `std::env::var`, `std::process::id`,
  `available_parallelism`, `SystemTime`, or any RNG, which is to say nothing
  bans the effects steps 3, 4 and 6 are made of.
- **D34 does not cover this crate.** Its scope is "read a process-global
  session", validated against generated forks, and it *explicitly excludes*
  `std::env::var` and `std::io::stdout()` on the grounds that the target is a
  child process of the shell. A host `staticlib` is not a child process, so the
  exclusions do not transfer and the reasoning cannot be borrowed.
- **The regex engine is conditional and the wrong dialect.** `onig` reaches the
  binary only under `experimental-bundled-coreutils`. What is unconditional is
  `fancy-regex`, which accepts backreferences and lookaround that the `regex`
  crate — the engine basic-cli documents these effects as using — rejects. So
  `regex_*` is either a new dependency or a silent dialect divergence, and the
  choice belongs in the log.
- **D36 is a mechanism, not a constant.** Its own words: *"This is not 'make
  `isatty` return false' — reporting no-terminal while still handing over the
  real one fixes nothing."* The constant is the consequence of stripping control
  sequences and handing over a pipe. D36 also names a rocjust-facing cost the
  first draft dropped: just's `[confirm]` becomes a host-rendered `wait_any`
  variant.

## The tiers disagree about who owns `main`

The largest thing the first draft missed, and it is upstream of every step.

basic-cli's host exports `pub extern "C" fn main` (`src/lib.rs:2296`). A Roc
platform host is a `staticlib` supplying the process entrypoint: `roc build`
links `libhost.a` with the compiled Roc object. So **under the native tier the
Roc app is the process and seahaven is a library it links.** Under D17's wasm
tier the direction inverts — seahaven is the process, embedding Wasmtime.

Every milestone so far assumed `brush-shell` is the binary, and D44's launcher —
which discovers the project, derives the grant, asks consent and installs the
mount table *before* anything else runs — lives in it. Under the native tier
that sequence has to happen inside a `main` the Roc toolchain generates the call
to. This is not an effect signature, and a trait over the effects does not reach
it.

**The resolution this plan takes:** the launcher becomes a library entry point
that `main` calls before `roc_main`, and `brush-shell`'s binary becomes one
caller of it rather than its owner. One implementation of D44 serves both tiers.
It is a step because it is a refactor of shipped code, not a new module.

## Prerequisites

Five defects found during review, which this plan is written against as fixed.
They are repo bugs rather than plan steps — each is reachable today from the
shell with no Roc involved — but every one sits on the path of an effect below.

1. **Environment inheritance is a passthrough.** `strip_host_environment` unsets
   `SHELL` and nothing else, so D21's three classes are decided and not built.
   `env_dict!` would hand a guest `SSH_AUTH_SOCK` and the host `PATH`.
2. **`HOSTNAME`, `UID`, `EUID`, `GROUPS` and `HOSTTYPE` are set ungated.**
   `is_confined()` appears once in `wellknownvars.rs`, for `SHELL`.
3. **`FileFacts` leaks host `dev`/`ino`/`uid`/`gid`.** Documented in the field's
   own doc comment as an open question.
4. **Job ids alias.** `id = self.jobs.len() + 1` with removal on reap, so
   spawn/complete/spawn collides with a live job. Step 5 hands this table to a
   guest as handles.
5. **`kill_external_commands_on_drop` is never set by the launcher**, though
   D43 calls it mandatory for sandboxed sessions.

**A sixth was reported and is not a bug.** The trust store has no tier field —
but there is no tier concept in the tree to record, so that is a prerequisite of
*this plan* rather than a defect in the shipped one. It is step 8.

## The change

**Step 0 — the launcher moves below `main`.** Nothing else can be built on a
sandbox that installs itself after the guest has started.

**Step 1 — the effect list is one Rust trait, exercisable from Rust.** D18's "no
drift" is unfalsifiable with a single implementor, so that is not the argument.
The argument is the gate: a trait the tests can implement and drive is what
makes a confined-versus-identity differential possible *without a
cross-language link* — a Rust test drives it with cargo alone, deterministically
and fast, which is why it is the gate the milestone's confinement claim rests
on.

**Step 2 — the filesystem effects.** `Path`'s 15 effectful calls. `list!`
inherits D45's skip. `path_type!` uses `symlink_metadata`, because a `SymLink`
variant that never appears is a lie no type catches. First task: measure D12's
path grammar against the corpus, since `notes:draft` is unnameable here.

**Step 3 — env, against the fixed policy.** D21's classes exist by then, so this
binds rather than builds. `temp_dir!` is synthesized. `exe_path!` is
`/bin/just`, which **requires D22's `/bin`** — so D22 either joins this
milestone or the effect returns a path that does not resolve, and that is a
decision to take rather than discover.

`cwd!`/`set_cwd!` are the session's, and must answer a **virtual** path.

`platform!` does *not* report the machine. The first draft gave it the real host
OS on the grounds that justfiles carry `[macos]`/`[linux]` attributes, which is
true and is not an argument for reading the machine: D12 records cap-std as
kernel-enforced on Linux and FreeBSD and **userspace-emulated on macOS and
Windows**, so the honest reading of that effect is "tell the guest whether its
confinement has TOCTOU windows". A **policy-declared target**, set by the
launcher, serves the justfile feature exactly as well and discloses nothing.

`pid!` returns a session-scoped id. `num_cpus!` returns the job limit, not the
machine's core count.

**Step 4 — stdio, which means building D28.** 58 sites resting on a mechanism
that does not exist. D28's correction applies: stdout and stderr stay separate
on the wire and merge only at render.

**Step 5 — `Cmd` as `spawn` + `wait_any`, blocking underneath.** The shape lands
now so no call site is re-ported later. `exec_*` must be implemented **through**
`spawn`/`wait_any` rather than beside it, or the re-port D25 warns about is
still owed. `exec_output_inherit_stdin!` is the hard one: just's backticks
inherit stdin, so a guest must hand its stdin to a child across D24's broker.

**Step 6 — signals, clock and RNG.** Signals are a queue the sandbox feeds; host
signals are not forwarded. **This breaks 9 corpus cases** that send real signals
to the binary, and `signals.just` requires forwarding SIGTERM to a child. The
expected delta is recorded before the step lands (gate 8).

Clock and RNG are session facts (D15) and hermetic-mode inputs (D14).
`Random.seed_u64!` must be unpredictable by default — `app/main.roc:9007` names
a directory with it.

**Step 7 — the Roc side, which is most of the deliverable.** A platform is not a
Rust crate. It is `main.roc` (the platform header), `Host.roc` (the hosted
declarations), and one module per exposed name — 13 of them, several large
(`Path.roc` alone is 28 KB). Plus `roc glue`, which regenerates the ABI
bindings, needs a Roc compiler *source checkout* rather than just the binary,
and has a `--check` mode because stale glue is a silent ABI mismatch. Plus
`roc_alloc`/`roc_dealloc`/`roc_realloc`/`roc_dbg`/`roc_expect_failed`/
`roc_crashed`, which are policy surfaces rather than boilerplate: `roc_crashed`
writes to stderr, which D28 must buffer, and `roc_alloc` is where D35's memory
budget will go.

The `Str` ABI carries a per-call refcount discipline — hosted functions receive
owned refcounted arguments and must release each exactly once — which is the
bulk of the line count and which step 1's trait sits above rather than removes.

**Step 8 — the tier is recorded in the trust store**, per D19. A milestone whose
only tier is the privileged one is D19's stated failure mode, so the record has
to exist before the second tier does.

**Step 9 — the host, then link it and run rocjust.** The host is two parts: the
marshalling (every hosted effect translating Roc's refcounted `Str`/`List`
to and from the session, with the release discipline above) and the link (a
broker-backed `Executor` and a compiled rocjust in the same binary). The
marshalling is checkable on its own, by host-side round-trips that build the Roc
values the compiler would pass; the link is the integration the central gate
exists to let the rest proceed without.

## Gates

The first draft built its gates on `check ban` and on rocjust's differential
harness. Neither can carry them. `check_ban` lints a fixture. And `diff.py`
compares the port against real `just` at a shared absolute path with a host
`HOME` — which is the identity-session blindness that let a re-vendor revert
three routing patches while `check forks` stayed green.

1. **The crate is a workspace member**, asserted by a test that reads
   `Cargo.toml` — not by `check ban`, which cannot see it. If the `staticlib`
   cannot be a member, this gate fails loudly and gate 3 becomes the only
   routing gate, which is a thing to say rather than to discover.
2. **The ban covers this milestone's effects.** New `clippy.toml` entries for
   `std::io::{stdout,stderr,stdin}`, `std::env::var*`, `std::process::id`,
   `available_parallelism`, `SystemTime::now` and the RNG, each added to the ban
   fixture so `check ban`'s "all firing" count covers them.
3. **The confined-versus-identity differential over the effect trait.** The
   central gate, and the one the first draft lacked. Every effectful call driven
   twice through step 1's trait — once under a restrictive mount whose root is a
   *subdirectory*, once under identity — and compared, with declared differences
   that fail when they stop differing. Runnable with cargo alone -- no Roc
   toolchain, no cross-language link -- which is what makes it the gate to lean
   on.
4. **Enumeration, not sampling.** Gate 3 exercises all **43** effectful calls,
   asserted by count against a list the test owns. The `ls`/`cp`/`du` regression
   is exactly what sampling misses.
5. **`cwd!` answers a virtual path**, not merely a different one per session.
   The weaker assertion passes while the guest is handed host layout.
6. **`exec_*` goes through `spawn`/`wait_any`**, asserted by the absence of a
   second path rather than by behaviour — behaviour is identical under a
   blocking implementation, which is why D25 warns about this shape at all.
7. **The env classes share one policy object**, asserted by adding a name to the
   deny list in one place and observing both `var!` and `dict!` change.
8. **The signal delta is recorded before step 6 lands.** The 9 corpus cases are
   listed by name with expected outcomes, and the list fails if a case not on it
   changes — the mirror rule `confinement_is_invisible` already applies.
9. **`upstream.sh` gets an exit status.** It ends in `|| true` and scrapes counts
   with grep, so it passes on a binary that dies at launch. Any gate built on it
   compares failing *names* against a recorded baseline, which is what
   `DIVERGENCES.md` already says to do.
10. **Not vacuous**: gate 3 carries a deliberate escape asserted to be caught,
    plus a control proving the identity side genuinely succeeds — both halves,
    as `the_differential_would_notice_an_escape` has them.

## Risk

**The native tier ships without a boundary, and there is no second tier to
compare it against.** D19's argument that nobody prefers native — because both
tiers are equally capable — requires two tiers. For this milestone's duration
there is one and it is the privileged one, which is D19's own stated failure
mode arrived at by sequencing. Step 8 records the tier; nothing *enforces* a
refusal to run untrusted code, and this plan does not pretend otherwise.

**The build is a pipeline, not a step.** `roc glue` needs a compiler source
checkout. The host is a `staticlib` whose exported symbols must survive
`strip = true`. The `dev` profile unwinds across an `extern "C"` boundary that
only release-profile `panic = "abort"` protects. Edition 2024 rejects bare
`#[no_mangle]`. The workspace lint wall denies `missing_docs`, `unwrap_used` and
`undocumented_unsafe_blocks` over a crate that is unsafe by construction, and
`check ban` requires exactly one `clippy.toml`, so a crate-local escape hatch is
itself a gate failure. None of this is hard; all of it is unbudgeted.

**The Roc link is a whole build, not a check.** `roc` is installed on this
machine, so nothing here is blocked on a missing toolchain -- the honest reason
steps 7-9 are not yet built is their size: `roc glue`, 13 module sources, the
`roc_*` runtime symbols, and a cross-language link of a `staticlib` against a
compiled Roc object. Gate 3 needs none of that, which is why it, not a full
rocjust run, carries the confinement claim.

**Signals remove the last interruption path in the shipping tier.** D35's
deadline does not exist, `epoch_interruption` needs the wasm tier, and host
SIGINT is not forwarded — so a native guest that loops has no stop short of
killing the process, which D35 rejected because it takes every sibling job with
it. D27 says DoS is in scope; in this tier it is not bounded.

## What stays behind

The wasm tier and its `Linker` binding. D25's scheduler, and with it `parallel::`
and the child pid `signals::` wants. D35's deadlines and memory budgets. D43's
handle tables — noting that step 5 ships the handle *ABI* while deferring the
lifetime mechanism, which is safe only while `spawn` really blocks. D16's grant
derivation from the justfile graph, which is rocjust's.

## Where it landed

Written after the first three steps. The plan above is left as written.

### Built (steps 1–8, with step 7's Roc sources checked by `roc`)

`brush-platform` is a new workspace member. [`PlatformEffects`] is the trait;
[`VfsPlatform`] is the one implementor, over a `brush_vfs::Session` and a
`SessionFacts`.

- **Step 1** — the trait, exercisable from Rust, which is what the central gate
  needed.
- **Step 2** — the twelve filesystem effects, routed through the facade.
  `path_type` on `symlink_metadata`; `dir_list` inheriting D45's skip; grammar
  rejection mapping to `NotFound`, with `notes:draft`/`con.txt` proven rejected
  rather than assumed absent.
- **Step 3** — the nine env effects, reading `SessionFacts` — a launcher's
  decisions, never the machine. `platform!` is declared; `pid!` and `num_cpus!`
  are session-scoped; `exe_path!` is `/bin/just` and does not resolve until D22;
  `cwd!` is virtual and `set_cwd!` moves the session, not the process.
- **Step 4** — the six stdio effects, and **D28 built to carry them**
  (`brush_platform::stdio`). An ordered segment log keeps stdout and stderr
  separate on the wire while preserving the render order that keeps just's echo
  attached to its output — the merge is a reading of the log, not a mutation of
  the bytes. The guest has no reader; only the host drains. stdin is a fixed
  source (D36: no terminal), EOF once piped input is drained.
- **Step 5** — `spawn`/`wait_any` and the four `exec_*` effects
  (`brush_platform::cmd`). The D25 shape lands: a handle from `spawn`, collected
  by `wait_any`, two held at once — blocking underneath, so the scheduler is
  absent and the shape is not. `exec_*` route **through** `spawn`/`wait_any`
  with no second path, pinned by removing the executor and watching
  `exec_status` fail exactly as `spawn` does (gate 6). Inherited output lands in
  the D28 log; captured output goes to the guest; `exec_output_inherit_stdin`
  hands the child the session's stdin. Handles are non-aliasing by construction
  — a monotonic counter, never reused — so the aliasing bug D25 warns of cannot
  arise. Execution itself is a seam, [`Executor`]: this crate does not depend on
  `brush-core` and spawns no host process, so the broker-backed executor (D2's
  predicate, D24's broker) is the link step's, exactly as the vfs binding is.
- **Step 6** — signals, clock, RNG (`brush_platform::runtime`). Signals are a
  queue whose *only* entry point is the sandbox's `deliver_signal`; the host's
  are not forwarded, so an ordinary run polls `0`, exactly as the plan says. The
  clock and RNG are session facts (D15) behind `Clock`/`Rng` traits — the
  default reads real time and real entropy, and D14's hermetic mode swaps in a
  pinned clock and a seeded RNG without the effects changing. The RNG being
  unpredictable by default is load-bearing: rocjust names a temp directory from
  it. tz offset defaults to 0, since D33 keeps `TZ` a session fact rather than a
  host reading.
- **Step 8** — the trust store records the tier (`brush-shell/src/trust.rs`).
  Consent is now `(mounts, tier)`, and the tiers are asymmetric: a native grant
  covers a later wasm run of the same mounts, but wasm consent never escalates
  to native — running the same code as host code in the vfs's address space is
  the more dangerous thing D19 exists to keep off the silent default. An
  untiered record from an older store defaults to wasm, so a native run
  re-prompts rather than inheriting a consent that predates the distinction. The
  launcher requests `Tier::Native`, the only tier that exists.
- **Step 7's Roc sources** — the platform (`platform/`): `main.roc`, `Host.roc`,
  and the thirteen exposed modules, adapted from the maintainer's `basic-cli`
  fork and trimmed to seahaven's confined surface (~50 hosted effects; no
  network, sqlite, sleep, locale, or file-reader handle). `roc check` type-checks
  it standalone, and a minimal app compiles against the exposed API, so the
  surface is proven consumable without the host or a link. A new
  `cargo xtask check platform` gate runs `roc check` (skipping with a note when
  `roc` is absent), because these files are invisible to `cargo` exactly as
  `forks/` is and would otherwise rot.
- **Gates 1, 3, 4, 5, 10**, all runnable with cargo alone -- no Roc toolchain,
  no cross-language link: workspace
  membership read from `Cargo.toml`; the confined-versus-identity differential;
  enumeration by count; cwd-is-virtual; and the non-vacuity escape with its
  identity control. Gate 7's "one policy object" is pinned at the shell level
  by `host_leak_tests` and, at the effect layer, by the env-reads-policy case.

### Not built, and why each stops where it does

- **Step 0 (launcher below `main`)** — a refactor that only matters once a Roc
  `main` calls it, and there is no Roc `main` yet. Building it now would move
  shipped code for a caller that does not exist.
- **Step 5's execution backend is built** — the shape landed first (above), and
  now the broker-backed [`Executor`] behind it: [`brush-broker-exec`], a
  workspace crate binding the platform's `Cmd` to `brush-core`'s D24 broker. It
  is closed-world by construction (D2) — it never runs `cmd.program` as a host
  program, only the trusted launcher re-invoked as `<launcher> --invoke-bundled
  <name>`, with `cmd.program` the bundled utility that dispatches — and the child
  is confined by the handshake, which serves it exactly the session's mounts.
  Proven end to end: six tests spawn the real `brush` trampoline over the real
  broker and assert confinement holds through the process boundary — an in-mount
  `cat` reads, a `/etc/hosts` or `../secret.txt` outside it fails with no bytes
  escaping. D43's generational handle table stays deferred; the non-aliasing
  counter is sufficient for a single session and does not need it.
- **Step 6's signal *baseline*** — the queue, clock and RNG are built (above),
  but gate 8 (the 9 corpus cases the no-forwarding decision changes) is only
  measurable against a running rocjust, which is step 9. The mechanism exists;
  the measured delta waits on the link.
- **Step 9's host is built** (`brush-roc-host`, excluded from the workspace like
  `forks/`), and it is now the whole marshalling layer, not just the foundation:
  - the `roc glue` output vendored, the runtime symbols, and `main` building a
    real `argv` (`RocList<OsStr>`) before calling the compiled `roc_main`;
  - **all 55 hosted effects defined and exporting** — the 8 scalar ones wired
    directly, and the **47 refcounted ones** (`fs_effects`, `env_effects`,
    `io_effects`, `cmd_effects`, `misc_effects`) hand-marshalling Roc's
    `Str`/`List`/`OsStr` with the glue's per-argument release discipline, one
    shared choke point per crossing in `marshal`;
  - the allocator correctness the whole thing rests on: the exported `roc_alloc`
    family forwards to the glue's `DefaultAllocators`, so a value the host builds
    and Roc frees (or the reverse) meets one allocator, not two;
  - 13 host-side round-trip tests that build the owned Roc value the compiler
    would pass, drive each effect, and read the result back — catching every
    structural marshalling bug and, through the system allocator's abort, every
    double free. The differential and enumeration gates (3, 4) were extended to
    the 10 new filesystem effects the trait had lacked, so confinement stays
    invisible for them too, and the D46 file-time effects report the deferred
    `Unsupported` on both sides.

  Two decisions were taken here rather than discovered: the reachable file
  surface (rocjust's `Path` reaches `file_time_*`, `file_size`,
  `is_readable`/`is_writable`, `hard_link`, `rename`, `write_bytes`, `dir_create`
  — effects the step-1 trait had not carried) is now **capability-correct** —
  size truthful, readable/writable grant-derived — with the **time effects
  deferred to `Unsupported`** (D46 stays open); and outgoing paths cross as
  `Utf8` (D45), the honest encoding for a string namespace.

  The host is also wired as its own trampoline (D30): `main` registers the
  bundled coreutils and takes the `--invoke-bundled` dispatch fast path before
  any Roc code, and the installed session carries a [`brush-broker-exec`]
  executor over the same namespace — so a confined `Cmd` runs a bundled utility
  by re-invoking this binary, served this session's mounts. That pulls the
  launcher (`brush-shell`, coreutils registry only) into the linked binary, which
  is the self-trampolining native tier the plan named.

  What remains is only the link-and-run: building rocjust against `platform/`,
  linking `libhost.a`, and running its differential harness end to end. The
  **true ABI** — the calling convention across the language boundary, and
  leak-freedom under a real workload — is exercised only there; the round-trip
  tests reach everything short of it. Miri, run over the host crate's tests, is
  the intended leak gate for that layer once the glue's manual allocation
  arithmetic is vetted against it.

The stopping point is now the link itself: steps 1–8 are verifiable without the
toolchain, step 7's Roc is checked by `roc`, step 9's marshalling by the host
round-trips, and its executor by `brush-broker-exec`'s end-to-end confinement
tests. What is left is compiling rocjust against the platform and linking it with
the host — the one integration the central gate was built to let the rest
proceed without.
